Why does this happen mathematically?

Exact Interpolation vs. Tikhonov-like Regularization

In a Gaussian Process, predictions at a test input x* use the covariance matrix K_y = K(X,X) + σ_n²I. When σ_n = 0, at any training point x* = x_i, the posterior variance σ²(x_i) = k(x_i,x_i) - k(x_i,X) K(X,X)⁻¹ k(X,x_i) = 0 exactly. When σ_n > 0, adding σ_n² to the diagonal of K_y prevents K_y⁻¹ from forcing exact interpolation, allowing the mean curve to pass smoothly between noisy points while retaining non-zero epistemic uncertainty!

GP Posterior Predictive Equations
Mean μ(x*): k(x*,X) [K + σ_n²I]⁻¹ y
Latent Var σ²(x*): k(x*,x*) - k_*ᵀ [K + σ_n²I]⁻¹ k_*
Obs Var σ_y²(x*): σ²(x*) + σ_n²
